How to Connect Firebase for Live Multi-User Admin

Step-by-step instructions for adding real authentication and cloud database updates.

To allow school administrators to securely log in, publish notices, and upload photos directly from a browser without modifying HTML code manually, follow these steps using Google Firebase (which provides a generous free tier):

Step 1: Create a Free Firebase Project

  1. Go to https://console.firebase.google.com/.
  2. Click "Add project" and name it (e.g. st-thomas-kiliyanthara).
  3. Under Project Settings, click "Add web app" to obtain your project configuration keys.

Step 2: Enable Firebase Authentication

  1. Navigate to Authentication > Sign-in method.
  2. Enable Email/Password authentication.
  3. Add the school administrator's email (e.g. admin@stthomashss.org) under the Users tab.
  4. This ensures that only authorized staff with verified credentials can make changes.

Step 3: Enable Cloud Firestore

  1. Go to Firestore Database and click Create database.
  2. Set up collections such as announcements, gallery, and faculty.
  3. Set Firestore Security Rules to allow read access for the public website, and write access only for authenticated users: 
    service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

Step 4: Enable Firebase Storage (for Photos & Circulars)

  1. Navigate to Storage and click Get started.
  2. Configure rules to allow public downloads and authenticated uploads.
  3. Uploaded event photographs will generate direct public download URLs that can be saved into Firestore.
Alternative: Netlify CMS / Decap CMS
If deploying to Netlify, you can alternatively enable Decap CMS (formerly Netlify CMS). It uses Git commits under the hood to store content directly in your repository without any external database fees.
