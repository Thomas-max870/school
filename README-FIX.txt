St. Thomas Higher Secondary School - GitHub Pages path fix

This package matches a flat GitHub repository layout (HTML files, style.css,
script.js, and image files all in the repository root).

Upload/replace the files in this ZIP in the root of:
https://github.com/Thomas-max870/kiliyanthara

Keep all HTML pages and assets together in the root. Then wait for GitHub Pages
to redeploy and hard-refresh the site (Ctrl+F5).

This fixes the common path mismatch that occurs when the original css/, js/,
and images/ folders are uploaded as flattened root-level files.
